Declarative Rust UI
built for CrownOS

A SwiftUI-style toolkit for Rust. Build views once, drive them with signals, style them with Tailwind names and render them with Impeller on a dedicated thread.

  • Fine-grained signals with no locks or RefCell
  • Tailwind style methods and DOM event names
  • Impeller rendering on Vulkan with a GLES fallback
  • Animations that keep running when the UI thread stalls
  • One semantic tree for accessibility, tests and AI agents
  • Over 30 themed widgets in light and dark
